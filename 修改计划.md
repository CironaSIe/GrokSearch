## 二、各模块设计

### 2.1 `specialists/__init__.py`

```python
from enum import StrEnum
from abc import ABC, abstractmethod
from urllib.parse import urlparse
import httpx


class SourceType(StrEnum):
    GITHUB_ISSUE = "github_issue"
    GITHUB_PULL = "github_pull"
    ARXIV = "arxiv"
    WIKIPEDIA = "wikipedia"
    HACKER_NEWS = "hacker_news"


GLOBAL_UA = "GrokSearch/1.0 (https://github.com/GuDaStudio/GrokSearch)"


class SourceExtractor(ABC):
    """Extractor 实例在 router 中共享。match() 不可变，fetch_render() 的 client 由 router 管理。"""

    @abstractmethod
    def match(self, url: str) -> bool:
        """同步 URL 模式匹配（正则/字符串），不做网络请求。必须是无副作用的纯函数。"""
        ...

    @abstractmethod
    def kind(self) -> SourceType:
        ...

    @abstractmethod
    async def fetch_render(self, client: httpx.AsyncClient, url: str) -> str | None:
        """用传入的 client 请求 API，返回结构化 Markdown。失败返回 None。"""
        ...


class SourceRouter:
    def __init__(self, github_token: str | None = None, proxy: str | None = None):
        from .github import GithubIssueExtractor, GithubPrExtractor
        from .arxiv import ArxivExtractor
        from .wikipedia import WikipediaExtractor
        from .hackernews import HackerNewsExtractor

        self._extractors: list[SourceExtractor] = [
            GithubIssueExtractor(github_token),
            GithubPrExtractor(github_token),
            ArxivExtractor(),
            WikipediaExtractor(),
            HackerNewsExtractor(),
        ]
        self._proxy = proxy

    def resolve(self, url: str) -> SourceExtractor | None:
        """查找匹配的 extractor。"""
        # 标准化 URL：只保留 scheme + netloc + path
        parsed = urlparse(url)
        if parsed.scheme not in ("http", "https"):
            return None
        cleaned = f"{parsed.scheme}://{parsed.netloc}{parsed.path}"
        for ex in self._extractors:
            if ex.match(cleaned):
                return ex
        return None

    async def fetch(self, url: str, timeout: int | float) -> str | None:
        """匹配 extractor → 创建 client → 调用 fetch_render。异常或空结果返回 None。"""
        extractor = self.resolve(url)
        if extractor is None:
            return None
        try:
            async with httpx.AsyncClient(
                timeout=timeout,
                proxies=self._proxy,
                follow_redirects=True,
            ) as client:
                content = await extractor.fetch_render(client, url)
                if content and content.strip():
                    return content
        except Exception:
            pass
        return None
```

**关键设计点：**

- `match()` 是纯函数，无副作用、无状态——同一 extractor 实例可被多请求共享
- URL 标准化先剪掉 query/fragment，避免 `?utm_source=...` 干扰匹配
- `fetch()` 内部管理 client 生命周期，extractor 不接触 httpx 配置（proxy/timeout/verify）

### 2.2 `specialists/github.py` — GitHub Issues & Pulls

**URL 模式：**
- Issues: `https://github.com/{owner}/{repo}/issues/{number}`
- Pulls: `https://github.com/{owner}/{repo}/pull/{number}`
- 也匹配 `https://github.com/{owner}/{repo}/discussions/{number}`？（暂不，后续可加）

**API：** `GET https://api.github.com/repos/{owner}/{repo}/issues/{number}`

**Headers：** `Accept: application/vnd.github.v3+json`，`Authorization: Bearer {token}`（可选）

**限频：** 有 token → 5000/h，无 token → 60/h

**渲染结构：**
```markdown
# #{number} {title}
> **状态：** {state} | **作者：** {user.login} | **创建：** {created_at}
> **标签：** {labels}

{body}

---

**评论：**
> **@{user.login}** 于 {created_at}：
{body}
```

**匹配正则：**
```python
_PATTERN = re.compile(r"^https://github\.com/([^/]+)/([^/]+)/(issues|pull)/(\d+)$")
```

**返回值：** 提取 `match.groups()` 在 `match()` 中不存储状态，`fetch_render()` 中重解析 URL。

```python
class GithubIssueExtractor(SourceExtractor):
    _pattern = re.compile(r"^https://github\.com/([^/]+)/([^/]+)/issues/(\d+)$")

    def __init__(self, token: str | None = None):
        self._token = token

    def match(self, url: str) -> bool:
        return bool(self._pattern.match(url))

    def kind(self) -> SourceType:
        return SourceType.GITHUB_ISSUE

    async def fetch_render(self, client: httpx.AsyncClient, url: str) -> str | None:
        m = self._pattern.match(url)
        if not m:
            return None
        owner, repo, _, num = m.groups()
        api_url = f"https://api.github.com/repos/{owner}/{repo}/issues/{num}"
        headers = {"Accept": "application/vnd.github.v3+json"}
        if self._token:
            headers["Authorization"] = f"Bearer {self._token}"

        resp = await client.get(api_url, headers=headers)
        if resp.status_code != 200:
            return None
        data = resp.json()

        # 渲染
        lines = [
            f"# #{data['number']} {data['title']}",
            f"> **状态：** {data['state']} | **作者：** {data['user']['login']} | **创建：** {data.get('created_at', '')[:10]}",
        ]
        if data.get('labels'):
            labels = ', '.join(l['name'] for l in data['labels'])
            lines.append(f"> **标签：** {labels}")
        lines.append("")
        body = data.get('body', '')
        if body:
            lines.append(body)
            lines.append("")

        # 获取前 5 条评论
        comments_url = data.get('comments_url', '')
        if comments_url:
            # comments_url is already the full API URL
            headers["Accept"] = "application/vnd.github.v3+json"
            resp2 = await client.get(comments_url, headers=headers)
            if resp2.status_code == 200:
                comments = resp2.json()
                if comments:
                    lines.append("---\n")
                    lines.append("**评论：**\n")
                    for c in comments[:5]:
                        lines.append(f"> **@{c['user']['login']}** 于 {c.get('created_at', '')[:10]}：")
                        lines.append(f"> {c.get('body', '')}")
                        lines.append("")

        return "\n".join(lines)
```

### 2.3 `specialists/arxiv.py` — arXiv 论文

**URL 模式：**
- `https://arxiv.org/abs/{id}`
- `https://arxiv.org/pdf/{id}`
- `https://arxiv.org/abs/{id}v{N}`（带版本号）
- `http://arxiv.org/abs/{id}`（HTTP 也 ok）

**API：** `GET http://export.arxiv.org/api/query?id_list={id}`

**注意：** arXiv API 是 **HTTP** 不是 HTTPS！使用 `follow_redirects=True`。

**限频：** 1 请求/3 秒，单连接

**渲染结构：**
```markdown
# {title}

**作者：** {authors}
**分类：** {categories}
**提交日期：** {published}
**DOI：** {doi}
**摘要链接：** {arxiv_url}

{abstract}

---
*更多信息：[arXiv.org]({abs_url})*
```

**匹配正则：**
```python
_PATTERN = re.compile(r"^https?://arxiv\.org/(?:abs|pdf)/(\d+\.\d+)(?:v\d+)?$")
```

注意从 `/pdf/{id}` 和 `/abs/{id}` 中提取的 ID 是相同的。

### 2.4 `specialists/wikipedia.py` — Wikipedia 摘要

**URL 模式：**
- `https://{lang}.wikipedia.org/wiki/{title}`
- `http://{lang}.wikipedia.org/wiki/{title}`

**API：** `GET https://{lang}.wikipedia.org/api/rest_v1/page/summary/{title}`

**Headers：** 必须设 User-Agent（否则只有 10/min），建议 `GrokSearch/1.0 (https://github.com/GuDaStudio/GrokSearch)`

**限频：** 设 UA → 200/min；不设 UA → 10/min

**渲染结构：**
```markdown
# {title}

{extract}

---
*来源：[Wikipedia]({content_urls.desktop.page})*
```

**匹配正则：**
```python
_PATTERN = re.compile(r"^https?://([a-z-]+)\.wikipedia\.org/wiki/(.+)$")
```

### 2.5 `specialists/hackernews.py` — Hacker News

**URL 模式：**
- `https://news.ycombinator.com/item?id={id}`
- `https://news.ycombinator.com/item?id={id}&p={page}`

**API：** `GET https://hacker-news.firebaseio.com/v0/item/{id}.json`

**无需认证，无条件限制（Firebase 托管）。**

**渲染结构：**
```markdown
# {title}

**作者：** {by} | **分数：** {score} | **评论：** {descendants}

{text}

---
*来源：[Hacker News](https://news.ycombinator.com/item?id={id})*
```

**匹配正则：**
```python
_PATTERN = re.compile(r"^https://news\.ycombinator\.com/item\?id=(\d+)(?:&.*)?$")
```

注意：`text` 字段是 HTML。需要清理 HTML tags 或用简单 regex 提取纯文本？直接用 `re.sub(r'<[^>]+>', '', text)` 粗略清洗即可，不做完整 HTML 解析以保持轻量。

### 3.1 `config.py` — 新增配置

```python
@property
def github_token(self) -> str | None:
    return os.environ.get("GITHUB_TOKEN") or os.environ.get("GH_TOKEN")

@property
def specialist_proxy(self) -> str | None:
    """Specialist HTTP client 专用代理，不影响 Tavily/Firecrawl 链路"""
    return os.environ.get("SPECIALIST_HTTPS_PROXY") or os.environ.get("SPECIALIST_HTTP_PROXY")

@property
def specialist_enabled(self) -> bool:
    return os.environ.get("SPECIALIST_ENABLED", "true").lower() not in ("false", "0", "no")
```

## 四、Proxy 处理逻辑

`SPECIALIST_HTTPS_PROXY` / `SPECIALIST_HTTP_PROXY` 环境变量控制：

- 仅作用于 specialist 创建的 `httpx.AsyncClient`，不影响其他 provider
- 格式：`http://127.0.0.1:7890`
- 传给 `httpx.AsyncClient(proxies=proxy_url)` 即可

**为什么不能复用系统代理？** 因为系统 `HTTP_PROXY` / `HTTPS_PROXY` 通常被 Tavily、Firecrawl、Grok 等已有 provider 共用，加独立变量避免干扰。

## 五、错误处理矩阵

| 异常场景 | Extractor 返回 | Router 行为 | 最终 |
|---------|---------------|------------|------|
| URL 不匹配任何 extractor | match() → False | resolve → None, fetch → None | → Tavily |
| API 超时 | httpx 抛异常 | except → None | → Tavily |
| API 返回非 200 | `if resp.status_code != 200: return None` | → None | → Tavily |
| API 返回空内容 | fetch_render → "" | `content.strip()` → False | → Tavily |
| 网络错误（DNS/连接被拒） | httpx 抛异常 | except → None | → Tavily |
| GitHub 限频 403/429 | `if resp... != 200: return None` | → None | → Tavily |
| Wikipedia User-Agent 不足导致 429 | same | → None | → Tavily |
| router 初始化失败（ImportError） | — | `source_router = None` | → Tavily |
| extractor 代码 bug（意外异常） | 抛出 | except → None | → Tavily |

**结论：** 任何异常都不会影响下游 Tavily/Firecrawl/Grok 链路。
